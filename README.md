# Proyecto 1 Analisis de ConnectaTel
**Descripción:** Se analizó el comportamiento del negocio dentro de un rango especifico de tiempo, con el fin de construir un perfil estadístico del cliente así como los comportamientos atípicos de los mismos. Finalmente se construyó un segmento de clientes.

**Título:** Identificación y Análisis de Outliers con Python
**Desafío:** Se observaban varios Outliers durante las etapas exploratorias, debíamos confirmar si esto era genuino debido al contexto del negocio. O si era un problema de la calidad de datos.
**Proceso:** Primero empecé limpiando los datos y separando los outliers. A medida que avanzaba, noté que había valores nulos y también algunos sentinels que estaban afectando el análisis. Sin embargo algunos de los datos nulos pudieron ser imputados con el contexto de otras columnas también se estandarizaron fechas para un análisis mas limpio. 
**Resultado:** Al final se logro observar mediante el uso de matplotlib que la distribucion de usuarios y uso era simétrica, pero se detecto que un segmento en especifico de clientes tendía a mejorar su plan de telefonía. Esto ayudó a tomar una decisión informada del negocio así como también proporcioné sugerencias basadas en el contexto del negocio que podrían ser tomadas en cuenta.
